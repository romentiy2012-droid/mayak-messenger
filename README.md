# Маяк

Публичный интерфейс небольшого экспериментального чата. Сервер и история находятся на Meizu владельца. Для входа нужна личная ссылка-приглашение.

В этой папке нет базы сообщений, приглашений, паролей, ключей или настроек аккаунта zrok. HTTPS защищает соединение; сквозное шифрование не реализовано.
