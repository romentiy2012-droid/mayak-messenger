# Маяк 2.0

Закрытый общий PWA-чат: интерфейс на GitHub Pages, аккаунты, история и Realtime — Supabase. Meizu не требуется.

Адрес: https://romentiy2012-droid.github.io/mayak-messenger/

## Первый запуск

1. В Supabase настроить Email Auth и URL приложения. При включённом подтверждении адресов нужен собственный SMTP для писем произвольным пользователям; стандартный SMTP ограничен адресами команды проекта.
2. Выполнить `supabase/owner-invite.sql` в SQL Editor. Полученный одноразовый код хранить приватно, не добавлять в репозиторий.
3. В приложении выбрать регистрацию, указать почту, пароль, имя и код владельца. При включённом подтверждении почты подтвердить адрес.
4. Владелец создаёт приглашение кнопкой «Пригласить». На втором телефоне зарегистрировать отдельного участника по ссылке.

Новый гостевой код отменяет предыдущий неиспользованный код; действует 7 дней, используется один раз. Приглашённые видят всю историю общего чата.

## Push-уведомления

Web Push: приложение подписывает устройство, триггер базы вызывает Edge Function `push`, она шлёт уведомление всем, кроме автора. Разовая настройка в Supabase:

1. SQL Editor: выполнить `supabase/migrations/202611160002_push.sql`.
2. Edge Functions → Deploy a new function → Via Editor: имя `push`, вставить `supabase/functions/push/index.ts`, развернуть. В настройках функции выключить «Verify JWT with legacy secret».
3. Edge Functions → Secrets: добавить `VAPID_PRIVATE_KEY` (приватный ключ пары; в репозиторий не добавлять).

На устройстве: кнопка «Включить уведомления» в чате или в меню «⋯». iPhone — только из приложения, добавленного на экран Домой (iOS 16.4+). Android — Chrome/Яндекс/Firefox, лучше установленное приложение. Если чат открыт на экране, уведомление не показывается.

Смена VAPID-ключей: новый публичный — в `config.js` и `supabase/functions/push/index.ts`, приватный — в секрет; устройства переподпишутся при следующем открытии.

## Разработка

`npm ci`, `npm run build`, `npm test`.

`config.js` содержит только URL и публичный ключ. Секретные ключи здесь запрещены. Миграция создаёт RLS и ограниченные функции записи; таблица приглашений закрыта для прямого чтения. Тест проверяет права владельца, гостя, постороннего, одноразовые приглашения и идемпотентность сообщений.

## Ограничения

Старые аккаунты и история Meizu не импортированы: исходная база не предоставлена. HTTPS есть, сквозного шифрования нет. Push-уведомления требуют разовой настройки (см. выше) и разрешения на каждом устройстве. Бесплатный Supabase может приостанавливать неактивные проекты.
