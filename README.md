# Маяк

Закрытый общий PWA-чат: интерфейс на GitHub Pages, аккаунты, история и Realtime — Supabase.

Адрес: https://romentiy2012-droid.github.io/mayak-messenger/

## Первый запуск

1. В Supabase: Authentication → Sign In / Providers → Email — включён, **Confirm email выключен**. Участники входят по имени: приложение само превращает имя в технический адрес `u_…@mayak.app`, писем на него не приходит, поэтому подтверждение почты пройти нельзя.
2. Выполнить по порядку миграции из `supabase/migrations/` и развернуть функции `push` и `reset` (обе с выключенной проверкой JWT).
3. Выполнить `supabase/owner-invite.sql` в SQL Editor. Полученный одноразовый код хранить приватно, не добавлять в репозиторий.
4. В приложении выбрать «Регистрация», указать имя, пароль и код владельца.
5. Владелец создаёт приглашение кнопкой «Пригласить». На втором телефоне участник регистрируется по ссылке.

Новый гостевой код отменяет предыдущий неиспользованный код; действует 7 дней, используется один раз. Приглашённые видят всю историю общего чата.

## Вход и забытый пароль

- Для входа нужно имя, указанное при регистрации, и пароль. Имя в чате можно поменять («Участники и ваше имя») — для входа остаётся прежнее. Аккаунт, созданный раньше по настоящей почте, входит по этой почте.
- Участник забыл пароль: владелец открывает «Участники, имя и пароли» → «Сбросить пароль» и отправляет участнику ссылку. Она одноразовая, действует сутки, новая отменяет предыдущую. Участник открывает её, задаёт новый пароль и сразу входит; приложение показывает имя для входа.
- Владелец забыл свой пароль: Supabase → Authentication → Users → нужный пользователь → сменить пароль.
- Как устроено: код из ссылки хранится в базе только в виде хэша (миграция `…0004_reliability.sql`), пароль меняет функция `supabase/functions/reset` через служебный API авторизации.

## Push-уведомления

Web Push: приложение подписывает устройство, триггер базы вызывает Edge Function `push`, она шлёт уведомление всем, кроме автора. Разовая настройка в Supabase:

1. Выполнить `supabase/migrations/202611160002_push.sql` (в ней адрес функции проекта — при смене проекта поправить).
2. Развернуть Edge Function `push` из `supabase/functions/push/index.ts` с выключенной проверкой JWT («Verify JWT with legacy secret»).
3. Приватный VAPID-ключ положить в Vault: `select vault.create_secret('<ключ>','mayak_vapid_private_key');` (или в секрет функции `VAPID_PRIVATE_KEY`). В репозиторий не добавлять.

Надёжность: сообщение считается отправленным только после ответа push-сервисов. При временном сбое функция повторяет отправку сама (три попытки), а база раз в минуту (pg_cron, задача `mayak-push-retry`) заново вызывает функцию для недоставленного — до шести раз в течение 15 минут и только по тем устройствам, которым не дошло. Нужна миграция `…0004_reliability.sql`.

На устройстве: кнопка «Включить уведомления» в чате или в меню «⋯». iPhone — только из приложения, добавленного на экран Домой (iOS 16.4+). Android — Chrome/Яндекс/Firefox, лучше установленное приложение. Если чат открыт на экране, уведомление не показывается.

Смена VAPID-ключей: новый публичный — в `config.js` и `supabase/functions/push/index.ts`, приватный — в секрет; устройства переподпишутся при следующем открытии.

## Возможности чата (2.2)

Тёмная тема, ответы, реакции, изменение и удаление своих сообщений, «прочитано», «печатает…», счётчик непрочитанных, звук нового сообщения. Нужна миграция `supabase/migrations/202611160003_features.sql` (после `…0002_push.sql`) и актуальная версия функции `push`.

## Разработка

`npm ci`, `npm run build`, `npm test`.

Код приложения — модули без сборки: `app.js` (точка входа) и `js/`: `core` (состояние, помощники), `session` (вход, получение сообщений), `messages` (лента, обновляется по частям), `composer` (поле ввода, черновики), `actions` (меню сообщения, жесты), `dialogs` (окна), `push`, `viewport`, `sound`. `cloud.js` — всё общение с Supabase. Новый файл нужно добавить в список `SHELL` в `sw.js`, иначе он не попадёт в офлайн-кэш. Недописанное сообщение хранится на устройстве и переживает перезапуск.

`config.js` содержит только URL и публичный ключ. Секретные ключи здесь запрещены. Миграция создаёт RLS и ограниченные функции записи; таблица приглашений закрыта для прямого чтения. Тест проверяет права владельца, гостя, постороннего, одноразовые приглашения и идемпотентность сообщений.

## Ограничения

HTTPS есть, сквозного шифрования нет. Push-уведомления требуют разовой настройки (см. выше) и разрешения на каждом устройстве. Бесплатный Supabase может приостанавливать неактивные проекты.
