# Маяк 2.0

Закрытый общий PWA-чат: интерфейс на GitHub Pages, аккаунты, история и Realtime — Supabase. Meizu не требуется.

Адрес: https://romentiy2012-droid.github.io/mayak-messenger/

## Первый запуск

1. В Supabase настроить Email Auth и URL приложения. При включённом подтверждении адресов нужен собственный SMTP для писем произвольным пользователям; стандартный SMTP ограничен адресами команды проекта.
2. Выполнить `supabase/owner-invite.sql` в SQL Editor. Полученный одноразовый код хранить приватно, не добавлять в репозиторий.
3. В приложении выбрать регистрацию, указать почту, пароль, имя и код владельца. При включённом подтверждении почты подтвердить адрес.
4. Владелец создаёт приглашение кнопкой «Пригласить». На втором телефоне зарегистрировать отдельного участника по ссылке.

Новый гостевой код отменяет предыдущий неиспользованный код; действует 7 дней, используется один раз. Приглашённые видят всю историю общего чата.

## Разработка

`npm ci`, `npm run build`, `npm test`.

`config.js` содержит только URL и публичный ключ. Секретные ключи здесь запрещены. Миграция создаёт RLS и ограниченные функции записи; таблица приглашений закрыта для прямого чтения. Тест проверяет права владельца, гостя, постороннего, одноразовые приглашения и идемпотентность сообщений.

## Ограничения

Старые аккаунты и история Meizu не импортированы: исходная база не предоставлена. HTTPS есть, сквозного шифрования нет. Сообщения обновляются при открытом приложении; фоновых push-уведомлений нет. Бесплатный Supabase может приостанавливать неактивные проекты.
